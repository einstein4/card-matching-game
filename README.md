# 체세포분열 카드 게임

체세포분열 5단계(간기·전기·중기·후기·말기)를 빠르게 구분하는 반응속도 카드 게임입니다. Next.js + Tailwind CSS로 만든 독립 실행 프로젝트입니다.

## 게임 방법

- 화면 상단에 5개의 고정 슬롯(간기/전기/중기/후기/말기)이 있습니다.
- 그림 카드 5장과 특징 문장 카드 13장, 총 18장이 무작위 순서로 한 장씩 등장합니다.
- 카드를 보고 알맞다고 생각하는 슬롯을 클릭해 배치합니다.
  - 정답: 카드가 공개된 후 경과 시간에 따라 점수가 선형으로 줄어듭니다(0초=5점 → 3초=1점, 이후 최소 1점 유지).
  - 오답: 1점이 감점되며 카드는 사라지지 않고 다시 시도할 수 있습니다. 정답 슬롯이 잠깐 강조되어 힌트로 표시됩니다.
- 18장을 모두 맞히면 결과 화면에서 최종 점수와 시기별 정답률을 확인할 수 있고, 다시하기로 재도전할 수 있습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 열면 게임을 시작할 수 있습니다.

### 빌드

```bash
npm run build
npm run start
```
